Política de privacidade

Agentes locais · última atualização: 25 de novembro de 2026

Quem usa

O Agentes locais é um aplicativo de uso pessoal. A única pessoa que o utiliza é o seu próprio desenvolvedor, com a sua própria conta Google. Ele não é oferecido ao público.

Quais dados do Google são acessados

O aplicativo acessa o Gmail com permissão somente leitura para:

  • consultar as mensagens que o usuário pedir;
  • ler o conteúdo e os anexos dessas mensagens;
  • ler o endereço de e-mail da conta conectada, para mostrar qual conta está em uso.

O aplicativo não envia, apaga, move, marca nem altera nenhuma mensagem.

Como os dados são usados e guardados

  • As mensagens e os anexos lidos são guardados apenas no computador do usuário, criptografados.
  • Os dados servem só para administrar as informações do próprio usuário, de acordo com o que ele pedir.
  • O acesso à conta Google (token de autorização) também fica guardado criptografado no computador.
  • Não há servidor próprio: nenhum dado é enviado ao desenvolvedor nem a terceiros, vendido, usado para publicidade ou para treinar modelos de inteligência artificial.

Se algum dia uma função nova precisar enviar dados para fora do computador, esta política será atualizada antes, dizendo o que é enviado, para quem e por quê.

Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como apagar os dados e revogar o acesso

  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/connections.
  • Os dados guardados ficam só no computador do usuário e podem ser apagados por ele a qualquer momento.

Contato

Pelo e-mail de suporte exibido na tela de autorização do Google.
